Sotto's standalone converter uses an audio-only FFmpeg argument path adapted
from OpenConverter's desktop ffmpeg command core (src/main/ffmpeg.js).
The GUI, media decoders, network integrations, Android code and
Electron shell of OpenConverter are not included.
