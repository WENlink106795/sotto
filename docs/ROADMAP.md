# 路线图与创意池

## 已实现（v0.1）

- VTT/SRT → LRC，含编码选择（UTF-8 / BOM / GB18030）
- 命名清理 + 音频/字幕严格同名 + 删除字符可视化
- 同目录/跨目录智能配对 + 低置信度警告
- 封面候选画廊 + cover.jpg（可选 JPEG 转换）
- WAV/FLAC/APE 等 → MP3/M4A（ffmpeg）
- 方案预览、两阶段重命名、运行日志、一键撤销
- 三套主题 + 强调色/圆角/密度/字号自定义
- 运行历史、本地优先、演示模式、无头截图

## 近期候选

1. **界面内手动配对**：核心已支持 `manualPairs`，补一个“未匹配项 → 选择音频/字幕”的交互，解决极低相似度或命名完全无关的作品。
2. **封面写入音频内嵌标签**：ffmpeg `-map 0 -map 1 -c copy -disposition:v attached_pic`，解决只读内嵌封面的播放器。
3. **双语字幕合并**：同时存在 `xxx.zh.vtt` / `xxx.ja.vtt` 时合并成一条 LRC（可切换语言顺序）。
4. **ASS/SSA 基础转换**：解析对白行与样式，忽略特效；覆盖更多字幕来源。
5. **文件夹监视**：监听下载目录，出现新作品时自动生成方案并通知。
6. **CLI / headless 模式**：`sotto --plan D:\ASMR --apply`，方便 NAS/脚本用户。
7. **重复作品检测**：按音频指纹/时长/标题聚类，提示重复或不同版本。
8. **响度统一**：可选的 EBU R128 / ReplayGain 标签写入（不重新编码）。
9. **章节与曲目拆分**：读取 CUE/章节文件，把整轨拆成独立音轨并同步字幕。
10. **便携模式**：配置放到 exe 旁，适合 U 盘携带。
11. **多语言界面**：中文 / English / 日本語。
12. **字幕时间轴微调**：在应用内预览 LRC 并整体偏移/缩放。
13. **封面自动推荐**：按分辨率、构图、文件名评分，默认选中最佳候选。
14. **批量命名模板**：`{circle} - {title} [{code}]` 之类的模板与占位符。
15. **操作对比报告**：导出 CSV/HTML，记录每个文件的旧名、新名、删除字符、体积变化。

## 明确不做

- 账号、云同步、遥测；
- 音乐库播放器（Sotto 专注“整理”，播放交给用户现有设备）；
- 破解/DRM 相关功能。
